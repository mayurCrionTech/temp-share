Yes. Since you've moved it to:

```text
C:\Users\A365_A_RPMAYUR\PM2\
```

and the file is now:

```text
C:\Users\A365_A_RPMAYUR\PM2\pm2-monitor.ps1
```

use this command to recreate the scheduled task under your user:

```cmd
schtasks /delete /tn "PM2 Process Monitor" /f
```

Then:

```cmd
schtasks /create /tn "PM2 Process Monitor" /tr "powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\Users\A365_A_RPMAYUR\PM2\pm2-monitor.ps1" /sc minute /mo 1 /ru ".\A365_A_RPMAYUR" /rp *
```

It will ask for your **Windows login password**.

Then verify:

```cmd
schtasks /query /tn "PM2 Process Monitor" /v /fo list
```

Make sure you see:

```text
Run As User: .\A365_A_RPMAYUR
```

Then force a test:

```cmd
schtasks /run /tn "PM2 Process Monitor"
```

And check:

```cmd
type "C:\Users\A365_A_RPMAYUR\PM2\pm2-monitor.log"
```

**One more thing:** inside `pm2-monitor.ps1`, make sure the log path is also updated to:

```powershell
$logFile = "C:\Users\A365_A_RPMAYUR\PM2\pm2-monitor.log"
```

The PM2 path should remain:

```powershell
$pm2 = "C:\Users\A365_A_RPMAYUR\AppData\Roaming\npm\pm2.cmd"
```
